# NFL Big Data Bowl UNAM

Proyecto oficial del evento. Leo desarrolla el análisis y la API en Arch; Pablo desarrolla el dashboard en Windows. El hallazgo se documentará después de validar el dataset oficial en partidos reservados.

## Inicio

Desde la raíz, ejecutar `sh .hackathon/setup.sh` en Arch o `.\.hackathon\setup.cmd` en Windows. Verificar con el mismo comando y `--check`. Colocar los datos en `data/`. El backend expone `GET /health`. La compilación del frontend queda en `dashboard/dist/`.

## Entrega

Documentar la decisión del coach, el hallazgo, los conteos, la incertidumbre y las limitaciones. Los participantes confirman la declaración de autoría. Generar el ZIP para AWS con el comando de instalación seguido de `--entregar`.
